# دليل المدرب — استخدام بوابة التدريب التربوي / Trainer guide

**Duration / المدة:** 2 hours · **Audience / الفئة:** all portal users

| Time | Activity / النشاط | Notes |
|---|---|---|
| 0–10 | Welcome and objectives / ترحيب وأهداف | read the five objectives |
| 10–30 | Chapter 1: signing in / الدخول والأمان | each person turns on two-step verification live |
| 30–55 | Chapter 2: finding and registering / البحث والتسجيل | trainees register for a practice programme |
| 55–80 | Chapter 3: courses and exams / الدورات | run the practice exam together |
| 80–100 | Chapters 4–5: certificates, help / الشهادات والمساعدة | report a practice problem |
| 100–120 | Final assessment / الاختبار النهائي | pass mark 70 % |

**Materials / المواد:** projector, practice accounts (Settings → Test accounts), the e-kit `EKIT-PORTAL`, trainee guide.
**Tips:** let trainees do each step on their own device; keep the "?" button in view.
