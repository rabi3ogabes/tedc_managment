# Hero slider photographs

The homepage slider shows an illustrated scene of Qatar for each slide. To use real
photography, add high-resolution landscape images (≥ 2400 × 1350, JPG, < 600 KB) here
with these exact names — each photo automatically replaces its illustration:

| File | Slide |
|------|-------|
| `doha-skyline.jpg` | Doha West Bay skyline / Corniche |
| `ministry-of-education.jpg` | Ministry of Education and Higher Education (official photo) |
| `museum-of-islamic-art.jpg` | Museum of Islamic Art or another national landmark |
| `qatar-heritage.jpg` | Heritage / desert / Souq Waqif scene |

Use only images you hold the rights to (e.g. official ministry media library, licensed stock).
