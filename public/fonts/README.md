# Qatar Sans

The platform's default typeface is **Qatar Sans**, the Qatar Government typeface
(https://gba.gco.gov.qa/ar/guidelines/brand-identity/). It is licensed and distributed through the
Government Communications Office, so it is not bundled in this repository.

Add the licensed web fonts here with these names (or upload them in **Admin → Brand Studio → Typography**):

- `QatarSans-Regular.woff2` (400)
- `QatarSans-Medium.woff2` (500)
- `QatarSans-Bold.woff2` (700)

Devices that already have Qatar Sans installed use it directly. Otherwise the platform falls back to
Tajawal (Arabic) and Inter (English).
