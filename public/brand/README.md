# Official logos

Place the official logo files here (or upload them in **Admin → Brand Studio → Identity**).
The header, footer, dashboard sidebar and certificates use them automatically; when a file is
missing the platform falls back to its built-in mark.

| File | Usage |
|------|-------|
| `logo-ar.png` | Arabic logo on light backgrounds (e.g. Ministry of Education and Higher Education — Arabic) |
| `logo-en.png` | English logo on light backgrounds |
| `logo-ar-white.png` | Arabic logo for dark backgrounds (optional — otherwise the regular logo is rendered in white) |
| `logo-en-white.png` | English logo for dark backgrounds (optional) |

Use transparent PNG (or WebP), ≥ 400 px high. Obtain the files from the official source
(e.g. the Ministry's media / brand team) and follow the Qatar Government brand guidelines for
clear space and co-branding: https://gba.gco.gov.qa/ar/guidelines/brand-identity/
