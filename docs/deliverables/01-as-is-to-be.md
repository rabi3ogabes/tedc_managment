## أولًا: العمليات الحالية (As-Is) ⚑
مصدر هذا القسم كراسة الشروط وجدول الأدوار وممارسات المركز المعروفة؛ كل بند مُعلَّم ⚑ يجب تأكيده في ورش العمل مع المركز.
1. **تحديد الاحتياج** ⚑: استبيانات ورقية/إلكترونية متفرقة ومقترحات من المدارس بلا تحليل فجوات موحّد.
2. **الخطة السنوية** ⚑: تُعدّ في جداول إلكترونية وتُعتمد بمراسلات؛ لا تتبّع لتنفيذها.
3. **التسجيل** ⚑: ترشيح من المدارس والمديريات برسائل وجداول؛ المقاعد تُدار يدويًا.
4. **الحضور** ⚑: كشوف ورقية، يُدخل لاحقًا.
5. **التقييم والشهادات** ⚑: اختبارات ورقية/خارجية وشهادات تُعدّ يدويًا.
6. **القياس والأثر** ⚑: استبيانات رضا محدودة دون قياس أثر أو مكسب معرفي.
7. **الساعات والرخص المهنية** ⚑: سجلات منفصلة لدى الموارد البشرية والرخص.

## ثانيًا: العمليات المستهدفة (To-Be) — كما نُفّذت في المنصة
| العملية | التدفق المستهدف (مختصر) |
|---|---|
| دورة الاحتياجات | فتح دورة ← استبيانات وملاحظات صفية وتقييمات ← فجوات مرتبة ← مقترحات برامج ← اعتماد |
| اعتماد الخطة | مسودة من الاحتياجات ← مراجعة ← إرجاع/اعتماد (توقيع) ← خط أساس ← تغييرات مبرَّرة ← تنفيذ ومتابعة الانحرافات |
| التسجيل | أهلية آلية ← موافقة المدير ← اعتماد المركز ← قائمة انتظار بترتيب أولوية ← تخصيص مقاعد ← انسحاب بسياسة |
| الحضور والأعذار | QR متجدد/بصمة/دفتر ← تحقق الموقع ← غياب وأعذار وقرار ← إشعارات |
| الاختبارات | بنك أسئلة ← تكوين ← أداء مع مراقبة ← تصحيح (آلي/يدوي) ← نتائج وتحليل |
| النجاح والشهادات | قواعد نجاح لكل برنامج ← استثناءات مسجّلة ← إصدار وتوقيع ورمز تحقق |
| التقييم والأثر | استبيان رضا ← مكسب معرفي ← أثر بعد 90 يومًا ← تقرير تقييم يُعتمد |
| التطوير المهني | ساعات سنوية بمصادرها ← مسارات مهنية ← رخص وتنبيهات |
| الورش الداخلية | مقترح المدرسة ← اعتماد ← اعتراف بالساعات |
| اللوجستيات | قاعات ومبانٍ وحجوزات وتجهيزات ومنع التعارض |
| المدفوعات | سعر حسب الفئة ← سلة وحجز مقعد ← بوابة الدفع ← فاتورة ← استرداد بسياسة |

الرسوم التفصيلية (BPMN) تُصدَّر من مصادر Mermaid في `docs/architecture/` وتُرفق بعد اعتماد ورش العمل.

# As-Is / To-Be process analysis (English copy)

## As-Is ⚑ (to be confirmed in workshops)
Needs gathered through scattered forms; the annual plan kept in spreadsheets and approved by correspondence with no execution tracking; nominations by letters and lists with manual seat control; paper attendance sheets; paper or external exams and hand-made certificates; limited satisfaction surveys with no impact or knowledge-gain measurement; professional-development hours and licences held in separate records.

## To-Be (as implemented)
Needs cycle → gap analysis → programme proposals → annual plan (approval, baseline, change log, deviation alerts) → two-stage registration with eligibility, priority-ranked waiting list and seat pools → attendance (rotating QR, biometric, register, geofence) with excuses → assessments (question banks, proctoring, grading) → passing rules and certificates with verification → satisfaction, knowledge gain and 90-day impact → CPD hours, career paths and licences → internal workshops → logistics → payments for paid courses. Detailed BPMN diagrams are exported from the Mermaid sources after workshop sign-off.
