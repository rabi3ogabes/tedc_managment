- [ ] عنوان نقطة الاستقبال في موقع الوزارة واسم ترويسة المفتاح وقيمته
- [ ] صيغة الخبر والفعالية المقبولة (الحقول، الوسوم، الصور) وكيف يتعامل الموقع مع التحديث والحذف

| الإعداد | سري | الافتراضي | الوصف |
|---|---|---|---|

شغّل هذه الحالات من تبويب «حالات الاختبار» أولًا على الإجابات المسجّلة، ثم على النظام الفعلي (القراءة فقط) بحضور الوزارة:

| الحالة | العملية | النتيجة المتوقعة |

## English

**Ministry website**

News and events flagged for export are pushed to the Ministry website's intake address.

### What the Ministry provides

- [ ] The system address (test environment first, then production)
- [ ] The authentication type and credentials (key, account or certificate)
- [ ] TEDC's outbound addresses added to the Ministry allow-list
- [ ] Real sample requests, responses and error codes
- [ ] A test account or test data for the joint session
- [ ] The website's intake address and the name and value of the key header
- [ ] The news and event format accepted (fields, tags, images) and how the site treats updates and removals

### What is set up in TEDC

Open the card and fill in the settings below, then press “Check connection”. Then compare the shipped contract and mapping with the Ministry's document in the Contract tab and edit what differs (every save is a version you can go back to).

| Setting | Secret | Default | Notes |
|---|---|---|---|
| `base_url` |  |  | The website's address, taken from the intake address (Communication → Ministry website). |
| `publish_path` |  |  | The path of the intake address. |
| `publish_query` |  |  | A query string on the intake address, sent with every push. |
| `auth_header` |  |  | The header the key travels in (X-Api-Key when empty). |
| `api_key` | yes |  | The key the website expects. Secret. |
| `site_name` |  |  | The source name sent with every item. |

**Authentication in the shipped contract:** an API key in a header or query parameter (optional: left out when not set).

**Operations:**

| Operation | Request | Read-only |
|---|---|---|
| `publish_item` — Push a news item or event | `POST {{ settings.publish_path\|default:/\|raw }}` |  |

- Switching the integration off on the card stops every call at once and deletes nothing in TEDC.
- Go back to a previous version of the contract or mapping from Contract → Versions (it adds a new version equal to the old one), or “Reset to shipped” for what comes with TEDC.
- Switching to the training mode (driver: fake) returns the system to sample data with no outside connection.
- [ ] The rollback plan agreed: switch the integration off, or return to the previous contract version
