## English

**Udemy Business**

The centre's Udemy Business course catalogue, and the learners' activity per course, to see who completed a course and count its hours in the record.

### What the provider gives you

- [ ] A Udemy Business Enterprise subscription that includes the REST APIs, and an administrator account of the site
- [ ] The name of your site (the first part of its address: acme in https://acme.udemy.com)
- [ ] The numeric Account ID, shown in the API settings under “API documentation”
- [ ] The Client ID and Client Secret from Manage → Settings → APIs & Integrations (the secret is shown once)
- [ ] The reporting API enabled with user-course-activity (completion data can lag by up to 24 hours)
- [ ] Learners' accounts carry the same e-mail address TEDC has (or an external id that is the employee number)
- [ ] TEDC's outbound addresses allowed to reach your site on udemy.com, port 443

### What is set up in TEDC

Open the card and fill in the settings below, then press “Check connection”. Then compare the shipped contract and mapping with the provider's document in the Contract tab and edit what differs (every save is a version you can go back to).

| Setting | Secret | Default | Notes |
|---|---|---|---|
| `subdomain` |  |  | The first part of your Udemy Business address: acme for https://acme.udemy.com. |
| `organization_id` |  |  | The numeric Account ID, in the API settings. |
| `client_id` |  |  | The client id (the app key) the provider gives. |
| `client_secret` | yes |  | The client secret the provider gives. |
| `base_url` |  |  | Only for a mock or a proxy; empty means https://<subdomain>.udemy.com. |
| `completions_lookback_days` |  | `7` | How many days back each nightly check looks for completions (a provider's reports can arrive late). |
