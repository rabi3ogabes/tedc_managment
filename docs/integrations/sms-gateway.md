## English

**Hudhud and text-message gateways**

The text-message gateway: the request template, the encoding (GSM 7-bit or UCS-2, chosen by the text), the success rule, the message id and the delivery receipts.

### What the Ministry provides

- [ ] The system address (test environment first, then production)
- [ ] The authentication type and credentials (key, account or certificate)
- [ ] TEDC's outbound addresses added to the Ministry allow-list
- [ ] Real sample requests, responses and error codes
- [ ] A test account or test data for the joint session
- [ ] The approved sender id, and any message templates the operator requires to be approved
- [ ] The send path, the request and response format, the error codes, and what the encodings are called (UCS-2 / GSM)
- [ ] How delivery receipts come back: the address they go to, the signature and the delivery status table
- [ ] The sending credit, the rate limits and any limit on night sending

### What is set up in TEDC

Open the card and fill in the settings below, then press “Check connection”. Then compare the shipped contract and mapping with the Ministry's document in the Contract tab and edit what differs (every save is a version you can go back to).

| Setting | Secret | Default | Notes |
|---|---|---|---|
| `base_url` |  |  | The gateway's address (Settings → Notification channels → SMS). |
| `send_path` |  |  | The path messages are sent to. |
| `api_key` | yes |  | The token, when the gateway uses one. Secret. |
| `username` |  |  | The user name, when the gateway uses one instead of a token. |
| `password` | yes |  | The password that goes with the user name. Secret. |
| `sender` |  |  | The approved sender id. |
| `receipt_url` |  |  | The address TEDC gives the gateway for delivery receipts. |
| `receipt_secret` | yes |  | The secret that signs delivery receipts. Secret. |

**Authentication in the shipped contract:** a bearer token in the Authorization header, and a user name and password when there is no token.

**Operations:**

| Operation | Request | Read-only |
|---|---|---|
| `send` — Send a text message | `POST {{ settings.send_path\|default:/api/v1/messages\|raw }}` |  |

**Messages coming in from the system:**

- Signature: header `X-Hudhud-Signature`, hmac-sha256, hex
- Delivery receipts are read through the mapping (the receipt entity) and its status table.
